# Security policy

## Reporting a vulnerability

If you find a security issue in TrimTrack, please email **hello@trimtrack.fit** with "Security" in the subject line. Please do not open a public GitHub issue.

Include:

- what you found and where (page, API route or file)
- the steps to reproduce it
- the impact you think it has

You will get an acknowledgement within 3 working days. Please give a reasonable amount of time for a fix before sharing details publicly.

## Scope

- The web app at trimtrack.fit and its API routes
- The code in this repository

Personal data requests, such as access or deletion, go to privacy@trimtrack.fit.
